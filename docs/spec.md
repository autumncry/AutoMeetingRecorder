# MeetingScribe 首版设计

用户已明确授权实现；所有源码、测试、脚本在项目 code/。个人自用原生 app，不开发 ASR 服务端。

- SwiftUI 主窗口、菜单栏、设置；macOS 14.2+。录音与网络任务不依赖阅读窗口。
- 飞书优先。每秒读取 pmset 音频断言，按 attributed client PID 与应用归属识别候选；辅以飞书会议窗口/静音控件。启动稳定 3 秒、结束去抖 8 秒。查询失败不是会议结束。
- 不确定时本地暂存并通知；确认保留开头，拒绝/120秒未答复则停止并清理。拒绝后同一会话不重触发，直到信号离开。未确认绝不上传。
- Core Audio 系统音频 tap + 独立麦克风，原音轨与混音留存。默认跟随飞书静音：只有可靠 unmuted 才保留麦克风，unknown/muted 只录系统音频；原始麦克风文件也不得保存被禁用段。可显式选独立麦克风模式。
- 默认按 PLAUD 思路全系统录音，界面明确可能包含其他应用，不能称飞书独占。设备切换尝试恢复；不可恢复则保存已有数据。扬声器静音不主动清零远端声音。外放回声处理质量须实测。
- 本地音频导入、plaud.cn 分享链接解析。只下载可访问音频；登录/过期/缺音频明确报错，提供文件导入兜底。不执行分享页脚本、不复用浏览器凭据。
- ASR 多配置：multipart 转写或聊天 base64 音频，内网 HTTP、可选 key 入钥匙串；解析 text/segments/VibeVoice JSON。缺时间戳仅给块级时间。模型不硬编码。切块、有限并发、超时与重试，重新转写保留版本。
- LLM 使用可配置 OpenAI 兼容聊天接口，中文摘要保留英文术语，输出决策、待办和不确定事项。
- Markdown/JSON 文件本地保存，内置阅读、音频播放、时间跳转、Finder 打开、选择目录。API 失败不丢音频。
- SwiftPM 无第三方包，本机构建、ad-hoc 签名。不复用 PLAUD 私有源码/二进制。

## 验收边界

本轮验证编译、单测、本地 HTTP 契约、合成音频、UI 启动。麦克风/系统音频/辅助功能权限由用户授予；飞书实会静音边界与自动检测要设备验收。没有 H800 地址和密钥时，不声称真实端点已通过。PLAUD 分享具体样本未提供时，不声称所有链接兼容。
